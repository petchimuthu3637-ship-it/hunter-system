🎮 GAME SYSTEMS EXPLAINED
═══════════════════════════════════════════════════════════════════════════════

📊 LEVEL SYSTEM
   • Start at Level 1
   • Gain XP by completing quests
   • Each level requires: Level × 100 XP
   • Level up gives 10 bonus XP
   • Maximum level: 150
   • Progress shown on dashboard

🏆 RANK SYSTEM
   • 6 ranks: E → D → C → B → A → S
   • Need 1000 points per rank
   • Automatically rank up when points reach 1000
   • Rank shown on profile and leaderboard
   • Colored badges on leaderboard (Gold, Silver, Bronze)

🎯 QUEST SYSTEM
   • 3 active quests on dashboard
   • Different difficulty: Easy, Medium, Hard
   • Complete to earn XP and rank points
   • Progress shown with bars
   • Different quest types (Defeat, Collect, Train)

💎 INVENTORY SYSTEM
   • 50 item slots total
   • 4 rarity levels: Common, Rare, Epic, Legendary
   • Color-coded by rarity
   • Weapons and armor give bonuses
   • Potions can be used for XP
   • Search and filter functionality

🌍 LEADERBOARD SYSTEM
   • Global rankings of all hunters
   • Top 10 displayed
   • Your ranking shown (example: #256)
   • Filter by rank class
   • Search by hunter name
   • Badges for top 3 hunters

💝 DAILY REWARDS
   • Claim one reward per day
   • Get XP or gold
   • Random items
   • Timer shows when next reward available

🔧 CUSTOMIZATION GUIDE
═══════════════════════════════════════════════════════════════════════════════

CHANGE COLORS:
   1. Open css/style.css
   2. Find :root { section at top
   3. Change color values:
      --primary-color: #7c3aed;      ← Change this to your color
      --secondary-color: #0ea5e9;
      --bg-primary: #0f172a;
      etc.

CHANGE GAME PARAMETERS:
   1. Open js/dashboard.js
   2. Find the line: const xpRequired = level * 100;
   3. Change the number to adjust XP requirement
   4. Similar for other parameters

ADD NEW ITEMS:
   1. Open inventory.html
   2. Copy an existing item card
   3. Change name, icon, rarity, stats
   4. Save file

❓ FREQUENTLY ASKED QUESTIONS
═══════════════════════════════════════════════════════════════════════════════

Q: Do I need to install anything?
A: No! Just open index.html in a web browser.

Q: Does it work offline?
A: Yes, after first load it works completely offline.

Q: Where is data saved?
A: In your browser's localStorage (built-in storage).

Q: Can I export my data?
A: Yes! Open browser console and type: Hunter.export()

Q: How do I login?
A: Register first, then use same email/password to login.

Q: Why is it dark?
A: Dark theme is easier on eyes and looks professional.

Q: Can I change colors?
A: Yes, edit css/style.css and change CSS variables.

Q: What browsers does it work on?
A: Chrome, Firefox, Safari, Edge, and mobile browsers.

Q: Is data secure?
A: This is a demo. For production, add a secure backend.

Q: Can I add more pages?
A: Yes! Follow the pattern of existing pages.

Q: How do I debug?
A: Open browser console (F12) and check for errors.
