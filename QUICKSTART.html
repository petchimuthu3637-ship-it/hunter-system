🎯 First Time Setup

  1. Go to Landing Page (index.html)
  2. Click "Register" button
  3. Fill in Registration Form:
    • Hunter Name (3-20 characters)
    • Email Address (valid format)
    • Password (minimum 6 characters)
    • Confirm Password
    • Agree to Terms checkbox
  4. Click "Create Hunter Account"
  5. Automatically logged in to Dashboard

📖 Pages Overview

1. Landing Page (index.html)

Main landing page with hero section, features showcase, and call-to-action buttons.

2. Login Page (login.html)

Login with email and password. Option to remember email for next time.

3. Registration Page (register.html)

Create new hunter account with validation and terms agreement.

4. Dashboard (dashboard.html)

Main hub showing profile, statistics, active quests, and daily rewards.

5. Inventory (inventory.html)

Manage items with search and filter functionality. Equip items or use potions.

6. Leaderboard (leaderboard.html)

View global rankings and compete with other hunters.

🎮 Game Systems

Level System

  • Start at Level 1
  • Each level requires: Level × 100 XP
  • Earn XP by completing quests
  • Level up gives bonus XP
  • Max level: 150

Rank System

  • E-Class: Beginner (0 points)
  • D-Class: Intermediate (1000 points)
  • C-Class: Advanced (2000 points)
  • B-Class: Expert (3000 points)
  • A-Class: Master (4000 points)
  • S-Class: Legendary (5000 points)

Inventory System

  • 50 item slots maximum
  • 4 rarity levels: Common, Rare, Epic, Legendary
  • Equip items for stat bonuses
  • Use potions to gain XP
  • Search and filter items

Quest System

  • Track active quests
  • Difficulty levels: Easy, Medium, Hard
  • Earn XP and rank points
  • Daily quests available

👨‍💻 Developer Features

Console Commands

Open browser console (F12) and use these commands:

Hunter.init() // Initialize example data
Hunter.log() // Log all stored data
Hunter.clear() // Clear all data
Hunter.export() // Export data as JSON
Hunter.inventory() // View example inventory

Local Storage Data

All data is stored in browser's localStorage:

  • users - Array of all registered users
  • currentUser - Currently logged-in user
  • rememberEmail - Last used email (optional)

🎨 Customization

🔧 Troubleshooting

Pages Not Loading

  • Check that all files are in correct folders
  • Open in a modern web browser
  • Check browser console for errors (F12)

Login Not Working

  • Make sure you registered first
  • Check email and password are correct
  • Clear browser cache if issues persist
  • Use console: Hunter.log() to debug

Data Lost After Refresh

  • Check if localStorage is enabled
  • Check browser privacy settings
  • Try different browser
  • Increase localStorage limit if needed

Styling Issues

  • Hard refresh browser (Ctrl+F5)
  • Clear CSS cache
  • Check if style.css is loaded
  • Verify CSS file path is correct
