## 🔧 CUSTOMIZATION TIPS

### Change Colors
Edit `css/style.css` and modify the `:root` section:
```css
:root {
  --primary-color: #7c3aed;    /* Change this */
  --secondary-color: #0ea5e9;
  --bg-primary: #0f172a;
  /* ... more variables */
}
```

### Adjust Game Parameters
Edit `js/dashboard.js`:
- Change XP requirement: `const xpRequired = level * 100;`
- Change inventory slots: `const maxInventory = 50;`
- Change rank points needed: `const rankUpPoints = 1000;`

### Add New Pages
1. Create new HTML file
2. Copy navbar and sidebar from existing pages
3. Link CSS: `<link rel="stylesheet" href="css/style.css">`
4. Link JavaScript files
5. Add your content
6. Update navigation links

## ❓ QUICK TROUBLESHOOTING

### Pages not loading?
- Check if all files are in correct folders
- Use a modern web browser
- Try hard refresh (Ctrl+F5)

### Login not working?
- Make sure you registered first
- Check email/password are correct
- Use `Hunter.log()` in console to debug

### Data lost after refresh?
- Check if localStorage is enabled
- Check browser privacy settings
- Clear cache and try again

### Styling looks wrong?
- Hard refresh (Ctrl+F5)
- Check style.css is loaded
- Verify CSS file path is correct
